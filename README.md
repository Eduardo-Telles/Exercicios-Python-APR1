## 🎯 Sobre este repositório

Este repositório reúne exercícios de Python feitos durante a faculdade e por conta própria. A ideia é registrar minha evolução, praticar boas práticas (nomes claros, código organizado, comentários) e manter tudo em um só lugar.

Estou atualizando aos poucos, então novos exercícios aparecem com frequência.

## 📂 Como está organizado

Cada pasta reúne os exercícios de um assunto:

```
exercicios-python/
├── 01-basico/
├── 02-condicionais/
├── 03-lacos/
├── 04-listas/
├── 05-funcoes/
├── 06-arquivos/
└── README.md
```

> Os nomes das pastas acima são um exemplo. Ajuste conforme os assuntos que você for adicionando.

## 📚 Exercícios

| Assunto | O que pratica | Pasta |

| Condicionais | `if`, `elif`, `else` | [02-condicionais](./02-condicionais) |

## ▶️ Como executar

Você precisa ter o [Python 3](https://www.python.org/downloads/) instalado.

```bash
git clone https://github.com/Eduardo-Telles/exercicios-python.git
cd exercicios-python
python 01-basico/nome_do_arquivo.py
```

Troque `01-basico/nome_do_arquivo.py` pelo caminho do exercício que quiser rodar.
